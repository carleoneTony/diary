# Квесты · Маршрут А

Одностраничный PWA-дашборд: квесты дня по учебному плану + FUT-карточка + синк телефон↔ноут через GitHub Gist.

## Запуск (5 минут)
1. Создай репозиторий на GitHub (например `quests`), залей 4 файла: `index.html`, `manifest.json`, `sw.js`, `icon.png`.
2. Settings → Pages → Source: `main` / root → Save. Через минуту сайт на `https://<ник>.github.io/quests/`.
3. Телефон: открой в Safari → Поделиться → «На экран Домой».
4. Ноут: открой в Chrome/Safari, можно «Установить приложение».

## Синк
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Generate new token. Permissions: Account → Gists → Read and write. Срок — 1 год.
2. В приложении: Настройки → вставь токен → «Синхронизировать». Появится Gist ID.
3. На втором устройстве: тот же токен + тот же Gist ID → «Синхронизировать».
Дальше синк идёт сам при каждой отметке и при открытии приложения. Конфликты сливаются (сессии объединяются, ничего не теряется).

## Пинг в 18:00 (iOS)
Команды → Автоматизация → Время суток 18:00, пн–сб → «Открыть URL» → адрес сайта. Включи «Запускать сразу».

## Изменить расписание
Всё расписание — в `index.html`, блок `const CFG`. Квест = одна строка: трек, название, минуты, дни недели, фазы, ссылка. Фазы (рамп / семестры) — там же с датами. Правишь → коммит → через минуту обновится.

Правила
День закрыт = 2 сессии. Закрытый день продлевает стрик. Вс — свободно.
Пропуск (пн–сб): стрик сгорает, Дисциплина −3. Одна заморозка в неделю применяется сама — первый пропуск недели не считается. Две подряд — считаются.
Идеальная неделя (6 из 6 закрыто): Дисциплина +1.
Статы растут от сессий, каждый трек со своей скоростью. Полоса залита от 50 до 99. Дисциплина — множитель ко всем статам: 70 нейтрально, выше тянет вверх (до +5%), ниже — вниз. Рейтинг = средний стат ×0.82 + Дисциплина ×0.18.
Награды за тиры впиши сам в настройках — заранее и конкретно.

Синк и правила

Загрузи картинку в репо (Add file → Upload) и впиши имя, напр. avatar.png. Пусто — буква.

Синк ноут ↔ телефон (GitHub Gist)

Токен хранится только в этом браузере. Данные — в секретном Gist на твоём GitHub. На втором устройстве вставь тот же токен и Gist ID → «Синхронизировать». При расхождении сессии объединяются, не теряются.
Как поставить на телефон и получать пинг в 18:00
  1. Открой сайт в Safari → Поделиться → «На экран Домой». Это нужно, иначе iOS не даст ни офлайна, ни уведомлений.
  2. Уведомление: Команды (Shortcuts) → Автоматизация → «Время суток» 18:00, пн–сб → действие «Открыть URL» с адресом сайта. Это надёжнее web-push на iOS.
  3. Зал (пн/ср/пт): второй пинг не нужен — открыл после зала, остаток квестов уже виден.
Как создать токен для синка
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained → Generate.
  2. Permissions: Account permissions → Gists → Read and write. Срок — год.
  3. Вставь сюда, нажми «Синхронизировать». Gist создастся сам. Скопируй Gist ID на второе устройство.
Правила статов (для тонкой настройки)

Стат = база + сессии × шаг. База 55. Шаг: ENG 0.15 · DATA 0.3 · STA 0.4 · PROD 0.35 · PSY 0.5 · PHY 0.3. Дисциплина стартует с 70. Настроено так, чтобы при выполнении плана к лету 2027 выйти в Icon. Менять — в коде, блок CFG.gain.
